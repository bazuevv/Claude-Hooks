# Claude Hooks

Публичный установщик хуков Claude Code для macOS.

## Скачать

Текущая версия: **1.10.5 (build 28)**.

Скачайте `MacOS_Install-1.10.5.zip` из раздела Releases, распакуйте архив и откройте `MacOS_Install-1.10.5.app`.

Приложение поддерживает Mac с Intel и Apple Silicon и требует macOS 12 или новее. Если Gatekeeper не разрешает обычный запуск, откройте приложение через контекстное меню **Открыть**.

`settings_API.json` включён как шаблон с `YOUR-API_KEY` и `YOUR-API-URL`. Укажите собственные данные подключения перед использованием API-аккаунта.

> Это предварительная публичная сборка: интерфейс установщика ещё дорабатывается.
